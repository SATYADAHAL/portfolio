# satyadahal.com.np

Hand-written HTML, CSS and vanilla JS. No framework, no build step.

```
index.html                              main page
writing/index.html                      writing index (list of posts)
writing/bikram-sambat-in-kde-plasma.html write-up
404.html
assets/style.css                        all styles (tokens at the top, light + dark)
assets/js/main.js                       theme, logo, nav/section sync, carousels, stars, BS date, converter
assets/js/bs.js                         AD → BS conversion (port of nepalicalendar.cpp)
assets/js/bs-table.js                   BS 2000–2099 table, generated from KDE MR !1113
assets/img/                             screenshots (WebP), framed on a soft backdrop
                                        (*-card.webp); originals live in ../sources/img/
                                        *-sm.webp are half-size copies for phones (srcset);
                                        regenerate with: magick X.webp -resize 600x -quality 82 X-sm.webp
                                        (800x for the 1600-wide screens.webp)
assets/icons.svg                        icon sprite, generated by ../tools/build-icons.cjs
assets/swashes/                         ink brush strokes for the hero underline (Vecteezy,
                                        credited in the footer); see "Hero brush stroke"
og.png                                  link-preview image (1200×630); template in
                                        ../tools/og-card.html
assets/fonts/                           IBM Plex (SIL Open Font License), self-hosted
CNAME, robots.txt, sitemap.xml          GitHub Pages / SEO
manifest.webmanifest, sw.js             installable app (Android "Install app"); icons in
                                        assets/app/. sw.js is network-first; bump VERSION
                                        in it to clear old offline copies
llms.txt, llms-full.txt                 summaries for AI tools; regenerate the full one with
                                        python3 ../tools/build-llms-full.py
```

## Run locally

ES modules need a server, not `file://`:

```sh
python3 -m http.server 8000
```

Icons come from react-icons; to add one, edit `tools/build-icons.cjs` and run:

```sh
node tools/build-icons.cjs
```

## Hero brush stroke

The underline under "Software engineer" is one of four strokes in `assets/swashes/`:
`arc-bristle` (current), `wave-bristle`, `long-thin`, `heavy-arc`. To switch, change the
file name in the hero's `<use href="/assets/swashes/….svg#stroke"/>` in `index.html`, then
adjust `height` / `bottom` on `.swash-mark` in `style.css` if needed.

## Adding a post

1. Write `writing/<slug>.html` (copy the KDE write-up for the head, header and footer).
2. Add a row to the list in `writing/index.html` (newest first) and to its JSON-LD.
3. Add the page to `sitemap.xml`, `llms.txt` and `PAGES` in `../tools/build-llms-full.py`,
   then run `python3 ../tools/build-llms-full.py`.

## Contact form

Posts JSON to `email-endpoint.vercel.app/api/contact` with a reCAPTCHA v2 token. The
endpoint only accepts requests from `https://satyadahal.com.np`, so it can't send from
localhost. Google's script loads only once someone starts on the form.

## Deploy (GitHub Pages)

Push the contents of this folder to the repo's Pages branch (or `main` with Pages set to
"deploy from branch, / (root)"). `CNAME` keeps the custom domain.
