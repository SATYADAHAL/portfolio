Bikram Sambat support for Plasma’s alternate calendar

Plasma’s clock could show Chinese, Hebrew, Islamic and Ethiopian dates — but not the official calendar of Nepal. I wrote the C++/Qt provider that adds it: a century of government-published month lengths (BS 2000–2099) as compile-time tables, a fallback for dates outside them, and Devanagari labels.

Reviewed and merged by Nate Graham. It closes a feature request open since February 2025 and ships to every Plasma 6.8 user.

Picatu

Find yourself in event photos from a single selfie. A team project where I built the face-recognition service.

Read moreShow less
  • A team of three. My part was the recognition service: a Flask API with Celery workers on Redis, called by the team’s Node.js gateway.
  • Uploaded event photos are encoded by a multithreaded C++17 program I wrote on Dlib’s ResNet face model, built against CUDA. Threads share a pool of model instances, and each photo gets a 128-number face descriptor.
  • A guest’s selfie is encoded once and compared against every photo in the event. A distance of 0.6 or less counts as a match.

termrex

Star49 stars on GitHub

The Chrome Dino runner for the terminal, in C++17 with no libraries: just termios and ANSI escape codes.

Read moreShow less
  • Runs in any POSIX terminal, down to a bare Linux virtual console.
  • Asks the terminal if it speaks the Kitty keyboard protocol. If it does, ducking uses real key-release events; if not, a tunable key-repeat timer.
  • Sprites are drawn as ASCII art and compiled by a small Python script into ANSI cursor-skip strings and collision masks, so hits are exact to the character.
  • Delta-time game loop with rising speed. Pauses with a warning when the window gets too small, and always restores the terminal on exit.
  • Unicode by default, with an ASCII-only mode for consoles without it.
  • Packaged as an RPM from a spec file in the repo and published on Fedora COPR, so it installs with dnf install termrex. Elsewhere it builds with plain make on Linux, macOS and BSD.

  • Linux
  • Fedora

TriNetra

Violence detection for home CCTV: an AI service watches live camera feeds, records the moment something happens and alerts the owner’s phone.

Read moreShow less
  • A team of three. I built the backend: FastAPI services for auth, cameras and AI behind an API gateway, on PostgreSQL, all run with Docker Compose.
  • The AI service reads each camera’s RTSP stream with OpenCV and classifies sequences of frames with a MobileNet + BiLSTM model in TensorFlow.
  • Once violence holds for 30 frames it saves the clip, riding out short gaps so one incident stays one video, then stores a notification and shares the clip with the app.
