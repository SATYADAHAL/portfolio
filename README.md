# satyadahal.com.np

Personal site of Satya Prakash Dahal: hand-written HTML, CSS and vanilla JS, no framework
and no build step.

- `site/` is the website itself, published to the `gh-pages` branch. See `site/README.md`
  for the layout, running it locally and adding posts.
- `tools/` holds small scripts: the icon sprite, `llms-full.txt` and the link-preview image.
- `sources/` keeps the original screenshots the site's images are made from.

The previous Next.js version lives on the `nextjs-archive` branch.
